Markdown 语法帮助

以下是本阅读器支持的 Markdown 语法。左列为书写方式，右列为说明。

标题

# 一级标题文章主标题
## 二级标题章节标题
### 三级标题小节标题
#### 四级标题更细一级的标题
##### 五级标题五级标题（导出 Word 时按正文处理）
###### 六级标题六级标题（导出 Word 时按正文处理）

文字样式

**加粗文字**加粗显示
*斜体文字*斜体显示
***粗斜体***同时加粗与斜体
~~删除文字~~删除线
`行内代码`等宽字体显示代码

段落与换行

空一行分隔上下两个段落
行尾两个空格 + 回车段落内强制换行

列表

- 项目一无序列表（也可用 * 或 +）
1. 项目一有序列表，序号自动重排
- [ ] 待办事项未完成的任务项
- [x] 已完成事项已完成的任务项
缩进两个空格生成嵌套的子列表

引用

> 引用的内容块引用，可跨行书写
>> 二级引用引用的嵌套

代码块

```javascript
function hello() {
  console.log('Hello');
}
```
 用三个反引号包裹，首行反引号后写语言名可获得语法高亮。支持 JavaScript、Python、Rust、HTML、CSS、SQL 等 190 多种语言

表格

| 列名 1 | 列名 2 |
| --- | --- |
| 内容 A | 内容 B |
 第二行是分隔行，必须有。用 :--- 左对齐、:---: 居中、---: 右对齐

链接与图片

[链接文字](https://example.com)超链接
![图片说明](图片.png)插入图片，支持与文档同目录的相对路径

分割线

---一条水平分隔线

数学公式

$E = mc^2$行内公式
$$
\int_0^1 x^2 dx
$$
 独立成行的块级公式

Mermaid 图表

```mermaid
graph LR
  A[开始] --> B[结束]
```
 支持流程图、时序图、甘特图、类图等。点击图表可全屏查看

内联 HTML 与转义

<span style="color:red">红色文字</span>直接书写 HTML 标签
\* 不是斜体 \*用反斜杠转义特殊字符

文档综合信息

统计基于当前打开的文档。文件大小、时间与所有者信息来自本地文件系统。

释放以加载文件

支持 .md / .markdown / .txt / .html
